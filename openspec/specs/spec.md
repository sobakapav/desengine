# AI трансформатор (desengine)

Инструмент, который помогает собирать **дизайн сразу в коде**: проект, компоненты, workflow и связанные артефакты React-системы через итеративную работу с LLM.

Этот файл — “входная вики‑страница” спецификаций: здесь только обзор, термины и ссылки на более маленькие спеки.

## Статус и ближайшая цель

Ближайшая цель: поддерживать работающий MVP с **настраиваемым сетевым LLM-провайдером по ключу**.

## Термины (кратко)

- **Корневая страница состояния** — публичный экран `/`, на котором пользователь видит общую диагностику системы и следующие шаги до допуска.
- **Проект** — основная рабочая единица продукта, внутри которой живут компоненты, workflow и верстаки.
- **Страница допуска** — экран `/auth`, на котором пользователь проходит allowlist-проверку перед входом в защищённую часть продукта.
- **Компонент проекта** — одна из проектных дизайн-единиц, по которой проект может вести отдельную линию работы.
- **Workflow** — последовательность шагов проектной работы вокруг компонента, экрана, проекта или другого предмета работы.
- **Верстак (Workbench)** — materialized рабочая поверхность, привязанная к проекту, workflow и предмету работы.
- **Итерация (Iteration)** — один запуск LLM по промпту пользователя.
- **Промпты** — производственные системные инструкции и пользовательский ввод.

## Общее описание системы (вики-уровень)

1. Пользователь открывает `/`, видит общую страницу состояния системы и понимает, что уже готово для работы.
2. После успешного допуска пользователь открывает `/projects` и выбирает проект.
3. Внутри проекта пользователь создаёт компоненты, запускает по ним линии работы и продолжает workflow.
4. Система ведёт итерации вокруг проектной работы внутри текущего workflow.
5. Пользователь видит состояние workflow и связанных верстаков прямо в проектном контексте.
