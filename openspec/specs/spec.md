# AI трансформатор (desengine)

Инструмент, который помогает превращать **картинки (PNG) интерфейсного компонента** в **набор файлов React‑компонента** (код + истории Storybook), через итеративную работу с LLM.

Этот файл — “входная вики‑страница” спецификаций: здесь только обзор, термины и ссылки на более маленькие спеки.

## Статус и ближайшая цель

Ближайшая цель: поддерживать работающий MVP с **настраиваемым сетевым LLM-провайдером по ключу**.

## Термины (кратко)

- **Корневая страница состояния** — публичный экран `/`, на котором пользователь видит общую диагностику системы и следующие шаги до допуска.
- **Проект** — основная рабочая единица продукта, внутри которой живут компоненты и workflow.
- **Страница допуска** — экран `/auth`, на котором пользователь проходит allowlist-проверку перед входом в защищённую часть продукта.
- **Компонент проекта** — дизайн-единица внутри проекта, из которой можно запускать или продолжать workflow.
- **Workflow** — последовательность шагов проектной работы вокруг компонента.
- **Итерация (Iteration)** — один запуск LLM по промпту пользователя.
- **Промпты** — производственные системные инструкции и пользовательский ввод.

## Общее описание системы (вики-уровень)

1. Пользователь открывает `/`, видит общую страницу состояния системы и понимает, что уже готово для работы.
2. После успешного допуска пользователь открывает `/projects` и выбирает проект.
3. Внутри проекта пользователь открывает компонент и запускает или продолжает workflow.
4. Система ведёт итерации вокруг проектной работы, а не вокруг отдельной legacy-задачи.
5. Пользователь видит состояние workflow прямо в проектном контексте.
