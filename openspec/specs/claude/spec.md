# Адаптер Claude

## Purpose

Зафиксировать требования к отдельному адаптеру Claude в общем LLM-слое продукта.

## Requirements

### Requirement: Система поддерживает адаптер Claude

Система SHALL поддерживать отдельный адаптер для Claude.

#### Scenario: Оператор выбирает Claude
- **WHEN** конфигурация приложения переключена на Claude
- **THEN** система использует адаптер Claude для LLM-вызовов

### Requirement: Конфигурация Claude задаётся явно

Система SHALL брать параметры подключения к Claude из локальной конфигурации приложения.

#### Scenario: Оператор настраивает Claude
- **WHEN** оператор задаёт обязательные параметры подключения к Claude
- **THEN** система использует их без изменения кода

#### Scenario: Claude включён как активный провайдер
- **WHEN** оператор задаёт `LLM_PROVIDER=claude`
- **AND** задаёт `CLAUDE_API_KEY`, `CLAUDE_MODEL`, `CLAUDE_BASE_URL` и `CLAUDE_MAX_TOKENS`
- **THEN** система использует именно эти параметры для LLM-вызовов

### Requirement: Claude принимает изображения workflow-артефактов

Система SHALL передавать изображения workflow-артефактов в адаптер Claude, если они доступны в LLM-запросе.

#### Scenario: Start или iterate выполняется с картинками через Claude
- **WHEN** в LLM-запросе есть одна или несколько PNG-картинок, связанных с текущим workflow
- **THEN** адаптер Claude отправляет их провайдеру вместе с текстовой инструкцией

### Requirement: Ошибки Claude различаются по типам

Система SHALL различать как минимум следующие классы ошибок для Claude:
- неполная конфигурация;
- ошибка авторизации;
- недоступность endpoint;
- таймаут;
- невалидный ответ провайдера.

#### Scenario: Авторизация Claude не прошла
- **WHEN** провайдер возвращает ошибку авторизации
- **THEN** пользователь видит понятное сообщение об ошибке доступа к Claude
