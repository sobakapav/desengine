## Why

По level 3 пришла конкретная жалоба на противоречие: система работает с `styles.ts`, а часть описания/hidden checking путает пользователя именем `style.css` или `style.ts`.

Текущий репозиторий подтверждает минимум один реальный разрыв: `overview.md` говорит про `styles.ts`, а hidden check prompt требует `style.ts`.

## What Changes

- Выравнивается contract level 3 по имени style-файла.
- Устраняются противоречия между:
  - overview уровня;
  - hidden checking prompt;
  - файловым контрактом уровня и workbench.
- Если нужно, добавляется traceability-след на этот контур.

## Impact

- Пользователь перестаёт сталкиваться с проверкой, которая просит не тот файл, с которым реально работает система.
