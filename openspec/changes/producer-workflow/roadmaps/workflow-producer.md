# Roadmap: workflow-producer

`producer-workflow` ведёт roadmap workflow-модели как видимого производственного процесса продукта.

## Что фиксирует roadmap

- workflow перестаёт быть скрытой проекцией лабораторных уровней;
- downstream changes отдельно закрывают переходы, статусные состояния и связку с рабочими surface;
- tactical delivery остаётся у `dispatcher-workflow`, а producer удерживает рамку процесса.
