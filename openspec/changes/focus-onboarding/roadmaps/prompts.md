# Roadmap: Onboarding Prompts

## Владелец

`focus-onboarding` владеет roadmap prompt-линии онбординга и поддерживает его для `dispatcher-prompts`.

## Что направляет roadmap

- стартовые промпты и подсказки пользователя;
- согласованность текста с реальным onboarding flow;
- критерии, когда достаточно контентной корректировки, а когда нужен behavior-change.

## Правила downstream

- исследования нужны для непонятных пользовательских реакций и повторяющихся сбоев понимания;
- implement/fix changes обязательны, если prompt меняет фактическое поведение шага, а не только wording.
