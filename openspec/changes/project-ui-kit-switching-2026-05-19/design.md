## Техническая проработка

Технические детали реализации ведутся в GitHub issue:
- https://github.com/sobakapav/desengine/issues/8

OpenSpec в этом change фиксирует продуктовые требования и критерии приемки.

## Контекст

В репозитории уже есть конфигурация Sandpack UI kit'ов (`lib/lab/sandpack-ui-kits.config.ts`) и сборка Sandpack payload (`lib/lab/sandpack-preview.ts`) с параметром `uiKitId`.

В этом change добавляем доменный уровень «проект» и переносим выбор kit'а из ad-hoc параметров в проектную настройку, а также вводим режим интерпретации UI как «только HTML-теги».

## Проект (минимальный контракт)

Предлагаемый минимальный контракт:

- `ProjectId`: строковый идентификатор.
- `Project`:
  - `id`
  - `title`
  - `uiKitId`: строка (идентификатор kit'а из sandpack-конфига) или `none`
  - `uiMode`: `"html-tags"` (в рамках этого change)

Хранилище (пока минимально жизнеспособное):

- локальный storage/память лаборатории (в дальнейшем может быть вынесено в доменную БД/сервер, но это вне текущего change).

## Выбор UI kit «на лету»

Требование «без перезагрузки» трактуем так:

- переключение `project.uiKitId` вызывает пересборку Sandpack payload и «перезапуск» Sandpack preview (в пределах React-дерева лаборатории);
- при этом URL/страница не перезагружается, пользователь остаётся в том же контексте лаборатории.

## Режим `html-tags`

В режиме `html-tags` система:

- валидирует UI-описание: разрешены только HTML-теги (никаких абстрактных компонентов);
- не требует UI kit'а; достаточны базовые зависимости React (`uiKitId=none` допустим и предпочтителен).

Важно: это режим интерпретации UI-описания, а не «авто-рендер любых React-компонентов».

## Совместимость / диагностика

Переключение kit'а может приводить к несовместимости. В рамках этого change достаточно:

- детектировать «явные» ошибки (например, попытка использовать неразрешённые сущности в `html-tags`);
- отображать статус совместимости и сообщение в UI лаборатории;
- исключить падение всей страницы/лаборатории при runtime-ошибках preview.

## OpenSpec контракт

Изменение поведения должно быть отражено в OpenSpec:

- описать capability/scenarios для проекта, выбора kit'а и режима `html-tags`;
- зафиксировать источник truth для списка kit'ов (конфиг Sandpack UI kit'ов).
