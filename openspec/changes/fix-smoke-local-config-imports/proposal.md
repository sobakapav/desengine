## Why

Жалоба на `npm run smoke` полностью подтверждается текущим кодом: несколько tool-скриптов до сих пор импортируют `../lib/local-config.cjs`, хотя runtime уже использует `../lib/system/config/local.cjs`.

Это блокирующий setup bug: пользователь падает ещё до прохождения smoke-flow.

## What Changes

- Скрипты `smoke`, `repair-onboarding` и `allowlist-marker` переводятся на актуальный путь локального конфига.
- Добавляются проверки, что tooling-контур больше не зависит от удалённого legacy-path.
- Обновляется контракт setup-flow, чтобы подобный разрыв не повторялся после следующих переносов файлов.

## Impact

- `npm run smoke` перестаёт падать на старом импорте.
- Tooling-контур согласуется с текущей структурой `lib/system/config`.
