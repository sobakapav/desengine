## Context

Жалоба комбинирует runtime CSS-симптом и layout-симптом. Это похоже либо на неполную генерацию Tailwind CSS для пользовательских файлов, либо на контейнерный preview-contract, который переопределяет ожидаемую ширину.

## Goals

- Понять, является ли проблема Tailwind-generation bug, layout bug или их сочетанием.
- Зафиксировать поддерживаемый контракт preview для arbitrary values.
- Убрать расхождение между кодом пользователя и тем, что он видит в preview.

## Non-goals

- Не расширять бесконтрольно весь Tailwind surface без подтверждённого product-contract.

## Decisions

1. Жалоба берётся в работу как runtime bug, а не как пользовательская ошибка.
2. Если arbitrary values намеренно не поддерживаются, это должно быть выражено явно в контракте и UI, а не проявляться как молчаливый слом.

## Risks

- Можно закрыть только width-case и не заметить, что color/height arbitrary values ломаются тем же корнем.
