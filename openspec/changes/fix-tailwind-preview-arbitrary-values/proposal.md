## Why

Пользовательская жалоба по `res-button` указывает на два связанных дефекта preview-runtime:

- arbitrary Tailwind values (`w-[158px]`, `bg-[#50d71e]`) не применяются;
- ширина компонента в preview ведёт себя не так, как заявлено самим кодом.

Если это подтвердится, пользователь видит ложную картину: компонент может быть корректным, а preview показывает, будто Tailwind или layout задачи работают неправильно.

## What Changes

- Проверяется и фиксируется контракт preview-runtime для пользовательского Tailwind-кода.
- Исправляется или документируется механизм, из-за которого arbitrary values выпадают из итогового CSS.
- Отдельно закрывается вопрос с нежелательным растягиванием компонента в preview-контейнере.
- Добавляются проверки, что preview уважает заданные width/height/color arbitrary classes либо даёт предсказуемый supported-contract.

## Impact

- Preview перестаёт искажать поведение пользовательского кода.
- Пользователь меньше уходит в ложные workaround'ы через inline-style только из-за дефекта sandbox/runtime.
