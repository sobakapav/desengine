# Roadmap: Workbench Layout Space

## Владелец

`focus-features` владеет roadmap layout-пространства workbench и предоставляет его `dispatcher-workbench`.

## Контур roadmap

- композиция панелей и зон workbench;
- правила приоритета пространства между редактором, preview и вспомогательными блоками;
- влияние layout-решений на понятность workflow.

## Эскалация

- `producer-*`: если нужно переосмыслить layout-принципы и вести отдельный roadmap решений;
- `implement-*`: если меняется реальное пространство и поведение панелей;
- `fix-*`: если устраняется локальный layout-регресс без смены модели.
