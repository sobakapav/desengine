## Context

Этот change переводит только пользовательский язык текущей работы. Он не создаёт новый workflow
engine, а перестраивает surfaces так, чтобы onboarding-шаг объяснялся через цель workflow и ожидаемый
артефакт.

## Goals

- Убрать level-centric wording из ключевых onboarding surfaces.
- Сделать текущий шаг workflow главным смысловым состоянием.
- Сохранить понятный мост между legacy progress и новым surface-языком.

## Non-goals

- Не менять project entry surfaces.
- Не переписывать проверку и экран результата в этом change.
- Не менять внутренний storage contract уровней, если для этого нет отдельной необходимости.

## Decisions

1. Формулы вида `Уровень N из M` не должны быть главным заголовком пользовательской работы.
2. UI должен показывать цель текущего workflow-шага и его практический смысл.
3. Если legacy level-number ещё нужен, он может оставаться вторичным техконтекстом или быть скрыт.

## Risks

- Если тексты изменятся без пересборки progress labels, пользователь всё равно будет читать текущую работу как level flow.
- Если change полезет в check/result заранее, границы между waves размоются.
