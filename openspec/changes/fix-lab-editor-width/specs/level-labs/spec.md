## MODIFIED Requirements

### Requirement: Лаборатория использует Monaco для редактируемых файлов

Система SHALL использовать Monaco Editor как основной редактор для файлов, разрешённых к редактированию в лаборатории уровня.

#### Scenario: Пользователь открывает лабораторию уровня
- **WHEN** у уровня есть редактируемые файлы
- **THEN** система показывает эти файлы через Monaco Editor

#### Scenario: Пользователь открывает лабораторию уровня на desktop
- **WHEN** пользователь открывает лабораторию на desktop-ширине
- **THEN** редактор занимает максимум доступного места в своей рабочей колонке
- **AND** не раздвигает рабочую область шире доступного layout-контейнера
- **AND** список файлов остаётся отдельной боковой колонкой, а не причиной бесконечного горизонтального роста редактора
