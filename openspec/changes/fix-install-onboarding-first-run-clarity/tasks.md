## Тестовая часть change

Затронутые OpenSpec capability/scenarios:
- `external-local-onboarding`: первый проход локальной установки должен быть понятен и недвусмысленен.
- `onboarding-repo`: документация должна корректно объяснять, как система тянет onboarding и где возможны сетевые ограничения.

Уровни проверки:
- static/contract: обязательный.
- unit: не требуется, если правка ограничится текстами/спеками.
- component/browser: не требуется.
- integration: не требуется.
- e2e smoke: не требуется.
- live/provider: не требуется.

Команды запуска:
- `npm run test:traceability`

Mock/fixture-данные и credentials:
- Не требуются.
