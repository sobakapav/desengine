# Change: fix-hide-ui-kit-switcher-access

## Зачем

Текущая реализация переключения UI kit нестабильна для пользователя. Временная безопасная мера — убрать пользовательский доступ к переключателю в интерфейсе, сохранив зачатки реализации в коде.

## Что меняется

- UI-переключатель выбора UI kit скрывается из интерфейса лаборатории.
- Runtime- и data-layer для UI kit остаются в кодовой базе без удаления.
- Change рассматривается как временная заглушка до стабилизации UX/runtime поведения.

## Что не входит

- Удаление существующей логики `project.uiKitId`/`uiMode`.
- Полный отказ от направления UI kit.
