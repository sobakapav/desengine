# Roadmap: Component Sourcing

`producer-platform-component-sourcing-strategy` ведёт roadmap выбора готовых platform primitives.

- Определяет ожидания к решениям `reuse`, `adapt`, `build`.
- Не владеет direct implementation; согласует follow-up с dispatcher changes.
- Конфликт между producer-рекомендацией и dispatcher-прагматикой не скрывается.
