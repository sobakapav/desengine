## Подключение Mantine

Подключение выполняется через существующий конфигурационный слой Sandpack UI kit'ов (единый адаптер), без kit-specific логики в runtime.

Точки интеграции (ориентировочно):

- `lib/lab/sandpack-ui-kits.config.ts`: добавить запись Mantine (`id/title/dependencies/...`).
- `package.json`: добавить отсутствующие зависимости (если их нет в корневом `dependencies`), чтобы версионирование шло из одного места.

## Notes

- Версии зависимостей берём из корневого `package.json`.
- Если Mantine требует CSS/глобальные импорты, их подключаем через предусмотренный механизм `indexTsxImports`.
