# dispatcher-ui-kit

Диспетчер направления UI kit'ов. Релизный вклад текущего среза — проектное переключение UI kit'ов в Sandpack preview без перезагрузки, режим HTML-тегов без kit'а, диагностика ошибок preview и targeted e2e smoke.

Следующий возможный вклад, не в рамках текущего сеанса: расширять спектр доступных UI kit'ов через дочерние `implement-ui-kit-*` changes.
