# Change: producer-ui-kit

## Зачем

Нужен отдельный верхнеуровневый исследовательский поток по направлению UI kit, чтобы диспетчерские и fix/implement changes опирались на единый корневой контекст, а не были вложены в feature-фокус.

## Что меняется

- `producer-ui-kit` закрепляется под стратегическим фокусом `focus-features`.
- Диспетчерская и внедренческая ветка UI kit ведётся отдельно в feature-контуре (`focus-features`), без дочерней привязки к этому producer-change.
