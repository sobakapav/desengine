# dispatcher-project

Постоянный диспетчер доменной линии `Project` под `focus-domain`.

Этот change удерживает тактическую рамку project boundary: canonical `ProjectWorkspace`, отдельные task/workflow/workbench bindings, правила тяжёлой миграции project `UI kit` и маршрутизацию downstream `implement-*` / `fix-*` changes по линии `Project`.
