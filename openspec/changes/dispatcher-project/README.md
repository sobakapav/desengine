# dispatcher-project

Постоянный диспетчер доменной линии `Project` под `focus-domain`.

Этот change удерживает тактическую рамку project boundary: canonical `ProjectWorkspace`, компонентный и workflow-слой проекта, связку с locked workbench shell, правила тяжёлой миграции project `UI kit` и маршрутизацию downstream `implement-*` / `fix-*` changes по линии `Project`.
