# Roadmap: Project Roadmap Entity

`producer-project-roadmap-entity` ведёт roadmap сущности project roadmap.

- Формирует ожидания к project-scoped планированию и связанным артефактам.
- Передаёт downstream delivery через dispatcher changes.
- Тактические расхождения с dispatcher считаются частью продуктовой проработки, а не ошибкой.
