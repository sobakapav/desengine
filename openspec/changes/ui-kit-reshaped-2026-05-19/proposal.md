## Why

Нужно подключить Reshaped как Sandpack UI kit, чтобы можно было выбрать его в проекте через общий механизм переключения UI kit'ов.

## Зависимости

Этот change зависит от `project-ui-kit-switching-2026-05-19` и не должен реализовываться до его полного завершения.

## What Changes

- Добавляем Reshaped в конфиг Sandpack UI kit'ов (новый `uiKitId`).
- Фиксируем npm-зависимости и CSS/импорты (если требуются).
- Добавляем smoke-пример рендера.
