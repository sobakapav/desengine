# Roadmap: Dev Mode Project Work

`producer-dev-mode-project-work` ведёт roadmap project-scoped dev-mode контура.

- Определяет ожидания к модели `Project` и связанным рабочим артефактам.
- Не порождает direct implement/fix changes; согласует delivery через downstream dispatcher.
- Полезный конфликт допустим, если dispatcher предлагает более безопасную тактику, чем producer-ожидание.
