# Proposal: Принудительный maxLevel=3 для всех задач

## Контекст

Сейчас каждая задача хранит собственный максимум `maxLevel` в task catalog. Для текущего режима обучения нужно принудительно зафиксировать одинаковую глубину прохождения для всех задач.

## Цель

Сделать так, чтобы все задачи в runtime имели `maxLevel = 3` независимо от значения в `task catalog config.json`.

## Вне scope

- Добавление UI-настройки/тумблера.
- Миграция task catalog.
- Изменения структуры глобального каталога уровней.

## Изменение контракта (OpenSpec)

Меняется поведение чтения метаданных задачи: `maxLevel` нормализуется до фиксированного значения `3`.
