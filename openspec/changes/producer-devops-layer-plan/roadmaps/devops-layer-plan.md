# Roadmap: DevOps Layer Plan

`producer-devops-layer-plan` ведёт roadmap DevOps-слоя проекта.

- Фиксирует ожидания к pipeline, окружениям и operational guardrails.
- Передаёт delivery не implement-ветке, а downstream dispatcher changes.
- Конфликт между roadmap и тактическим delivery считается сигналом для уточнения стратегии.
