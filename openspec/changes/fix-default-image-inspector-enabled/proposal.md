# Change: fix-default-image-inspector-enabled

## Зачем

Инспектор изображения в лаборатории сейчас включается только через query-параметр `imageInspector=1`.
Для пользователя это выглядит как «инспектор пропал», хотя функция доступна.

Нужно сделать инспектор включённым по умолчанию и оставить query-параметр только для явного отключения/диагностики.

## Что меняется

- Инспектор изображения становится поведением по умолчанию в лаборатории.
- Query-параметр `imageInspector` сохраняется как override:
  - `imageInspector=0|off|false` отключает инспектор;
  - отсутствие параметра включает инспектор.
- Поведение фиксируется в OpenSpec и покрывается unit/source-contract проверкой UI-ветки рендера.

## Что не входит

- Изменение визуального дизайна инспектора.
- Новые инструменты инспектора (zoom presets, history, annotations).

## Пользовательский эффект

- Инспектор снова «виден сразу» без дополнительных параметров URL.
- Снижается когнитивная нагрузка: не нужно помнить скрытый флаг.
