## MODIFIED Requirements

### Requirement: Лаборатория может включать инспектор изображений

Система SHOULD поддерживать интерактивный просмотр вводных картинок в лаборатории через `image-inspector`.

#### Scenario: Инспектор изображения включён по умолчанию
- **WHEN** пользователь открывает лабораторию без query-параметра `imageInspector`
- **THEN** система показывает интерактивный инспектор для вводной картинки

#### Scenario: Пользователь явно отключает инспектор изображения
- **WHEN** пользователь открывает лабораторию с `imageInspector=0` (или `off` / `false`)
- **THEN** система показывает обычный image-render без инспектора
