# Roadmap: User Action Logging

`producer-user-action-logging` ведёт roadmap логирования действий пользователя.

- Формирует ожидания к смыслу, scope и потреблению action-логов.
- Передаёт runtime-delivery через downstream dispatcher changes.
- Если dispatcher ограничивает объём или порядок внедрения, это сохраняется как полезный конфликт ожиданий.
