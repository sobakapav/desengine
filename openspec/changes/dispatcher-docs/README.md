# dispatcher-docs

Забота о документации проекта в governance-контуре: OpenSpec workflow, process-команды, handoff, traceability и связанные инженерные инструкции.

Этот dispatcher не дублирует `dispatcher-doc`: внешний и общий инженерный documentation contract системы остаётся под `focus-public`, а `dispatcher-docs` ведёт только документацию самого governance-слоя.
