# Change: release-2026-06-10-architecture

Активный release change для стартовой волны архитектурной трансформации продукта с лейтмотивом «Начинаем трансформацию архитектуры продукта».

Внутри этой волны теперь есть не только `focus-tech` архитектурная линия, но и первая domain-wave вокруг сущности `Project`, которая пересекается с общей архитектурной трансформацией продукта.

Дополнительно в релиз заведён user-facing visual-language change `implement-editorial-shell-style-foundation`, чтобы путь `project -> workflow -> работа` не остался технически реализованным, но визуально разрозненным.

Текущий active срез релиза уже шире исходной project-wave: он охватывает не только `Project` как раздел, но и следующий пользовательский маршрут `project -> component -> workflow -> workbench -> preview`.
