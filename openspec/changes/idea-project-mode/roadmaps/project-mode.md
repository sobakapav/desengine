# Roadmap: Project Mode

## Владелец

`idea-project-mode` удерживает раннюю продуктовую гипотезу проектного режима как единого контура.

## Что входит в контур

- `Project Workspace` и project-scoped данные;
- задачи и workflow как сущности внутри проекта;
- roadmap проекта как следующая волна координации этапов, задач и прогресса.

## Что должно решиться до delivery

- какой минимальный `Project` нужен для первого среза;
- какие данные переводятся в project-scoped модель первыми;
- что именно входит в MVP project mode без roadmap-слоя;
- когда `Project Roadmap` становится следующей оправданной волной после стабилизации task/workflow слоя;
- как разбить контур на downstream producer/dispatcher/implement changes без преждевременной детализации.
