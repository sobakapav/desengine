## Why

`test:live` уже заявлен в тестовом слое, но пока это placeholder. При этом действующий контракт `testing-layer` уже требует, чтобы явный live/provider запуск читал credentials только из env или локальных некоммитимых файлов и показывал понятную диагностику отсутствующих переменных.

## What Changes

- Реализовать для `test:live` env-aware preflight без реальных provider-вызовов.
- Использовать уже существующие helpers чтения и диагностики test env.
- Обновить документацию тестового слоя под новый минимальный runnable live-контур.

## Non-goals

- Не выполнять в этом change реальные live/provider запросы.
- Не включать `test:live` в обязательный `test:full`.
- Не менять install-critical инфраструктуру.

## Impact

- Команда `npm run test:live` перестаёт быть пустым placeholder.
- Пользователь получает минимальный, но полезный preflight live-контура без риска случайных сетевых вызовов.
