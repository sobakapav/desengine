## MODIFIED Requirements

### Requirement: Проект имеет простой пользовательский config surface

Система SHALL давать пользователю простой способ прочитать и изменить конфигурацию проекта на странице `/projects/<projectId>` через явные пользовательские поля.

#### Scenario: Пользователь меняет UI kit проекта из canonical списка
- **WHEN** пользователь выбирает другой `uiKitId` для проекта
- **THEN** система использует canonical список доступных UI kit'ов
- **AND** этот список берётся из реестра системных `UI kit adapter`
- **AND** изменение сохраняется в `ProjectWorkspace.settings`
- **AND** пользователь видит только один выбранный UI kit без отдельного effective-режима

#### Scenario: Пользователь управляет UI kit в верхнем слое страницы проекта
- **WHEN** пользователь открывает `/projects/<projectId>`
- **THEN** система показывает явный верхний control управления UI kit проекта
- **AND** этот control объясняет, что поддержанные UI kit'ы поставляются внутри desengine
- **AND** не требует от пользователя вручную ставить зависимости kit'а
