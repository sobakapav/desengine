## ADDED Requirements

### Requirement: Лабораторный предпросмотр использует промышленный React-runtime

Система SHALL рендерить результат пользовательской задачи в лаборатории через промышленный React preview-runtime с поддержкой TypeScript, JSX, module imports и виртуальных файлов проекта.

#### Scenario: Пользователь открывает рабочий экран задачи
- **WHEN** пользователь открывает лабораторию начатой задачи
- **THEN** система собирает виртуальный preview-проект из рабочих файлов задачи
- **AND** рендерит результат через React preview-runtime
- **AND** не подменяет импортированные UI-компоненты простыми HTML-заглушками

#### Scenario: Пользователь меняет компонент и сохраняет файл
- **WHEN** пользователь изменяет `Component.tsx` и сохраняет файл
- **THEN** предпросмотр пересобирает виртуальный preview-проект
- **AND** показывает актуальный результат сохранённого компонента

### Requirement: Предпросмотр исполняет настоящие UI-компоненты

Система SHALL исполнять локальные UI-компоненты, импортированные пользовательским кодом из `@/components/ui/*`, с их реальной логикой props, variants и className composition.

#### Scenario: Компонент использует variant локального Badge
- **WHEN** пользовательский `Component.tsx` импортирует `Badge` из `@/components/ui/badge`
- **AND** рендерит `<Badge variant="ghost">`
- **THEN** предпросмотр использует настоящий `Badge`
- **AND** применяет классы, возвращённые `badgeVariants({ variant: "ghost" })`

#### Scenario: Компонент использует className поверх UI-компонента
- **WHEN** пользовательский компонент передаёт `className` в локальный UI-компонент
- **THEN** предпросмотр объединяет классы через реальную логику компонента
- **AND** пользовательский `className` влияет на визуальный результат

### Requirement: Предпросмотр применяет Tailwind CSS внутри preview-изоляции

Система SHALL подключать Tailwind CSS и базовые CSS tokens внутри preview-изоляции, в которой рендерится пользовательский компонент.

#### Scenario: Пользовательский компонент использует Tailwind-классы
- **WHEN** пользовательский `Component.tsx` содержит Tailwind-классы в `className`
- **THEN** предпросмотр применяет соответствующие CSS-правила внутри области результата

#### Scenario: UI-компонент генерирует Tailwind-классы через variant
- **WHEN** локальный UI-компонент добавляет Tailwind-классы на основе своего prop `variant`
- **THEN** предпросмотр применяет эти классы внутри области результата
- **AND** визуальное поведение не зависит от CSS внешней страницы лаборатории
