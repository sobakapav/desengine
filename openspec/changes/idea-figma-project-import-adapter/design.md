## Входы и режимы импорта (эскиз)

Возможные режимы:

- Import whole file (весь Figma file).
- Import selection (страницы/фреймы/компоненты по ids).

Входные параметры:

- `figmaFileKey`
- `nodeIds?`
- `importMode` (whole/selection)
- `projectTitle?`

## Выход: Project + Artifacts

Импорт создаёт:

- новый `Project` (или обновляет существующий — позже);
- набор `Artifacts` с типами:
  - `figma_tree_snapshot`
  - `figma_components_snapshot`
  - `figma_styles_snapshot`
  - `figma_assets_refs` (или экспортированные файлы)

## Секреты и доступ

MVP требования:

- токены/ключи доступа принадлежат пользователю;
- по умолчанию не сохраняем токен в небезопасном виде;
- импорт должен работать без утечки данных в логи.

## Стабильность и воспроизводимость

- хранить версию/время импорта;
- хранить ссылку на источник (file key) и параметры импорта;
- поддержать повтор импорта (re-import) как отдельный этап (позже).

## Тестирование (план)

- Unit/contract: парсинг/валидация конфигов импорта, схема артефактов.
- Integration: мок/Figma API adapter (контрактные ответы).
- Traceability: сценарии импорта ↔ тесты.
- E2E smoke (опционально): импорт (mock) → проект создан → артефакты доступны.
