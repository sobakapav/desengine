# Roadmap: Image Inspector

`producer-image-inspector` ведёт roadmap интерактивного просмотра вводных изображений.

- Определяет, какой пользовательский эффект и какие ограничения ожидаются от inspector.
- Передаёт delivery через dispatcher и downstream implementation.
- Несовпадение producer-ожиданий и dispatcher-тактики считается нормальным входом для уточнения границ.
