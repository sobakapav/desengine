# Change: producer-speed-and-load

Продюсерский change под `focus-quality`, который держит общий контур скорости и нагрузки системы.

Его задача не в том, чтобы сразу чинить код, а в том, чтобы:

- собрать и удерживать картину проблем со скоростью и утечками;
- определить, какая нагрузка на систему считается допустимой;
- зафиксировать, какие измерения и guardrail'ы нужны;
- организовать downstream-работы через `dispatcher` changes.

Этот change не должен брать на себя роль `dispatcher` или `implement`.
