## Контекст

- Родительский dispatcher управляет приоритетом и порядком реализации.

## Решение

- `npm run os:r` должен собирать список релизов только из активного каталога `openspec/changes`.
- Архив `openspec/changes/archive` исключается из чтения целиком, чтобы в вывод не попадали ни архивированные release, ни архивированные элементы состава.
- Документация `tools/README.md` и unit-тест синхронизируются с новым контрактом.
