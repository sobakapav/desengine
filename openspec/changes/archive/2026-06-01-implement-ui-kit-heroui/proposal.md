## Why

Нужно подключить HeroUI как Sandpack UI kit, чтобы его можно было выбирать для проекта через общий механизм переключения UI kit'ов.

## Зависимости

Этот change зависит от `dispatcher-ui-kit`: релизный срез по проектному переключению уже зафиксирован, а этот дочерний change расширяет набор доступных UI kit-адаптеров.

## What Changes

- Добавляем HeroUI в конфиг Sandpack UI kit'ов.
- Фиксируем зависимости и минимальный bootstrap (если требуется).
- Добавляем smoke-пример рендера.
