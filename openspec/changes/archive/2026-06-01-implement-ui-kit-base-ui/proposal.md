## Why

Нужно подключить Base UI как Sandpack UI kit, чтобы его можно было выбирать на уровне проекта через единый механизм переключения.

## Зависимости

Этот change зависит от `dispatcher-ui-kit`: релизный срез по проектному переключению уже зафиксирован, а этот дочерний change расширяет набор доступных UI kit-адаптеров.

## What Changes

- Добавляем Base UI в список Sandpack UI kit'ов (новый `uiKitId`).
- Фиксируем зависимости и (при необходимости) импорты.
- Добавляем smoke-сценарий рендера.
