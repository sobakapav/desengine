## Сущность: Expertise Attractor (эскиз)

- `Attractor`:
  - `id`
  - `title`
  - `kind` (skill / atom / superpower / checklist / template / workflow-fragment)
  - `description`
  - `sources[]` (ссылки на experiments/events, из которых обобщено)
  - `artifacts[]` (файлы/шаблоны/инструкции/кодовые фрагменты)
  - `signals` (метрики/признаки повторяемости)
  - `status` (candidate/validated/deprecated)
  - `version`
  - `createdAt/updatedAt`

## Выявление кандидатов

Источники сигналов:

- повторяемость одинаковых intent'ов/шагов workflow;
- повторяемость одних и тех же промптов/паттернов кода;
- повторяемость ошибок и их решений;
- ручная маркировка пользователем («это важно», «это хочу повторять»).

## Упаковка

Варианты упаковки (MVP-приоритет):

1) Skill (инструкция + шаблоны промптов + примеры).
2) Checklist (как последовательность проверяемых шагов).
3) Template (шаблонный блок для Prompt Builder, если он есть).

## Применение

Минимальные способы применить аттрактор:

- вставить/подключить skill в текущую задачу/промпт;
- применить checklist как шаги workflow;
- импортировать template в Prompt Builder.

## Тестирование

Исследовательский change: тесты не обязательны, но обязательно:

- определить, что именно будет тестироваться в последующих behavior-change changes;
- зафиксировать команды и уровни проверок для будущих этапов.
