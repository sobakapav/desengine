# Roadmap: Skill Map

`producer-skill-map` ведёт roadmap карты навыков.

- Определяет, какие связи между навыками и повторяемыми паттернами должны быть зафиксированы.
- Не порождает implement напрямую; работает через downstream dispatcher.
- Различие между producer-ожиданием и dispatcher-тактикой сохраняется как полезный конфликт.
