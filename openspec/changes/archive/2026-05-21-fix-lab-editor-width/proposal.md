# Change: fix-lab-editor-width

## Зачем

Сейчас кодовый редактор на странице лаборатории может раздвигать рабочую область по ширине вместо того, чтобы занимать только доступное место в своей колонке.

Для пользователя это выглядит как сломанный desktop-layout: рабочее полотно становится неуправляемо широким, появляется лишний горизонтальный разъезд, а редактор перестаёт ощущаться как часть контролируемого Workbench.

## Что меняется

- Фиксируется UX-контракт лаборатории: редактор кода не должен растягивать layout шире доступной области.
- Tabs/layout слой редактора получает явные ограничения по сжатию и ширине на desktop.
- Добавляется source-contract тест на наличие этих layout-ограничений в коде Workbench-редактора.
- В OpenSpec добавляется delta для `level-labs`, описывающая ожидаемое поведение редактора на desktop.

## Что не входит

- Полная переработка Workbench layout.
- Замена Monaco, Tabs или базовой структуры лаборатории.
- Изменение мобильного UX за пределами необходимой корректировки layout-контрактов.

## Пользовательский эффект

- Редактор занимает максимум доступного пространства в своей колонке.
- Лаборатория перестаёт разъезжаться по ширине из-за editor-pane.
- Desktop-workbench выглядит как ограниченное рабочее полотно, а не как бесконечная лента.
