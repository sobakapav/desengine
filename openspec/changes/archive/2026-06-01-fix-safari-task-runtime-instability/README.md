# fix-safari-task-runtime-instability

Исполнительский `fix`-change под `dispatcher-runtime`.

Чинит тяжёлый runtime-дефект: в Safari после запуска локального dev-режима приложение может работать крайне медленно, переставать открывать части интерфейса задач и в отдельных прогонах не доходить даже до экрана авторизации.
