# Roadmap: User Experience Generalization

`producer-user-experience-generalization` ведёт roadmap обобщения пользовательского опыта.

- Определяет, какие наблюдения должны превратиться в устойчивые продуктовые ожидания.
- Согласует delivery только через dispatcher changes, без direct implement children.
- Конфликты между producer-моделью опыта и тактической delivery-линией считаются частью системы.
