## Решение

Предпочтительный способ нормализации UI:

- выносить маленькие presenter-компоненты рядом с исходным компонентом;
- выносить event handlers / derived state в локальные helpers, если это не меняет поведение;
- не менять дизайн-систему и визуальный результат;
- для `components/ui/**` сначала оценить, является ли файл shadcn/vendor-style; долгоживущий waiver допустим только после явного решения.
