## MODIFIED Requirements

### Requirement: Локальная установка синхронизирует `/onboarding` из внешнего репозитория

Система SHALL синхронизировать локальный каталог `/onboarding` из внешнего Git-репозитория, заданного в локальной конфигурации запуска.

Система SHALL показывать диагностические тексты onboarding-ресурсов из конфигурации системных ресурсов, а не из кода диагностики.

#### Scenario: Локальная установка ещё не получила полный `/onboarding`
- **WHEN** локальный каталог `/onboarding` отсутствует или не содержит обязательный layout
- **THEN** система показывает, что onboarding-контент ещё не синхронизирован

#### Scenario: Локальный `/onboarding` пришёл не из того репозитория
- **WHEN** маркер синхронизации указывает на другой repo URL
- **THEN** система показывает, что onboarding-контент требует повторной синхронизации

#### Scenario: Диагностика показывает статус onboarding
- **WHEN** система собирает ресурсы `onboarding-config` или `onboarding-content`
- **THEN** summary, detail и инструкции берутся из конфигурации системных ресурсов
- **AND** код диагностики передаёт только condition и переменные синхронизации
