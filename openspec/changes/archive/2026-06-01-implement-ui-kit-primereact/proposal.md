## Why

Нужно подключить PrimeReact как Sandpack UI kit, чтобы он выбирался на уровне проекта через общий механизм переключения UI kit'ов.

## Зависимости

Этот change зависит от `dispatcher-ui-kit`: релизный срез по проектному переключению уже зафиксирован, а этот дочерний change расширяет набор доступных UI kit-адаптеров.

## What Changes

- Добавляем PrimeReact в конфиг Sandpack UI kit'ов.
- Фиксируем зависимости (включая CSS/темы, если обязательны для рендера).
- Добавляем smoke-пример рендера PrimeReact-компонента.
