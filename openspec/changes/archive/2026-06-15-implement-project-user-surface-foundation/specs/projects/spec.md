## ADDED Requirements

### Requirement: Проекты доступны как самостоятельный пользовательский раздел

Система SHALL показывать проекты в глобальной навигации и открывать их через отдельный route-слой, а не только изнутри Workbench конкретной задачи.

#### Scenario: Пользователь видит вкладку проектов в верхнем меню
- **WHEN** пользователь открывает любой основной экран продукта
- **THEN** в глобальной навигации есть вкладка `Проекты`
- **AND** она ведёт в canonical раздел `/projects`

#### Scenario: Пользователь открывает список проектов
- **WHEN** пользователь переходит в `/projects`
- **THEN** система показывает список проектов из canonical project registry
- **AND** отдельно отмечает active project

#### Scenario: Пользователь открывает страницу конкретного проекта
- **WHEN** пользователь открывает `/projects/<projectId>`
- **THEN** система показывает project overview для этого `ProjectWorkspace`
- **AND** не требует предварительно заходить в Workbench конкретной задачи
