## Why

Task runtime уже умеет жить в active project context, но пользовательский слой пока не говорит, к какому проекту относится задача. Это создаёт несколько проблем:

- задача выглядит как самодостаточная единица без project owner'а;
- на странице проекта нельзя увидеть его задачи;
- на странице задачи нельзя быстро понять, в каком проекте она сейчас исполняется;
- project-aware runtime остаётся невидимым и потому воспринимается как случайная техническая деталь.

## What Changes

- Ввести явную assignment-модель задачи к проекту как user-facing contract.
- Показать project binding на task surfaces:
  - в списке задач;
  - на экране конкретной задачи;
  - в переходах между задачей и проектом.
- Показать связанные задачи на странице проекта.
- Использовать canonical project/task runtime boundary, а не дублировать параллельный assignment shape.

## Impact

- Пользователь начинает видеть двустороннюю связь `проект <-> задачи`.
- Следующие project-facing waves смогут добавлять историю, workflow и workbench context уже поверх явной project assignment-модели.
