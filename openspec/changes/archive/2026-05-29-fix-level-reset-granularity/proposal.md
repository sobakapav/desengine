## Why

В жалобах повторяется понятное UX-трение: пользователь может сбросить только всю задачу, но не может вернуться к началу текущего уровня без потери работы по предыдущим уровням.

Текущее поведение подтверждено кодом:
- action [resetTaskRuntime](/Users/op/dev/sobakapav/desengine/lib/task/actions/files.ts) делает только полный reset задачи;
- header рабочей зоны предлагает пользователю только `Сбросить задачу`;
- для многоуровневой модели это означает лишнее повторное прохождение уже пройденных этапов.

Это уже влияет на взаимодействие с системой, особенно когда уровень зашёл в тупик или LLM испортила текущую стадию, а пользователь хочет просто начать текущий уровень заново.

## What Changes

- Ввести отдельный reset current level без полного обнуления всей задачи.
- Сохранить уже пройденные уровни и прогресс, который не относится к текущему уровню.
- Явно развести в UI два действия: “сбросить уровень” и “сбросить всю задачу”.

## Non-goals

- Не пересматривать всю модель task progression.
- Не менять историю уже завершённых уровней без необходимости.
- Не смешивать reset-level с возвратом к списку задач уровня или другими navigation-идеями.

## Impact

- Пользователь перестанет терять уже заработанный прогресс из-за локальной ошибки на одном уровне.
- Прохождение многоуровневых задач станет менее фрустрирующим и менее затратным по времени.
