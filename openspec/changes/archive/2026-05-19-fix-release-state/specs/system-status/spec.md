# Spec Delta: system-status

## ADDED Requirements

### Requirement: Корректное отображение успешной синхронности с релизом

Система SHALL корректно определять и отображать состояние, при котором текущий код соответствует последнему релизу.

#### Scenario: Пользователь запрашивает сводку состояния при работе на последнем релизе

- **GIVEN** система работает на коде, соответствующем последнему релизу
- **WHEN** пользователь открывает или запрашивает сводку состояния ресурсов системы
- **THEN** система показывает, что код синхронен с последним релизом
- **AND** система не показывает ложное сообщение об ошибке синхронности

#### Scenario: Система запущена в production-режиме

- **GIVEN** система запущена через `npm run start`
- **AND** текущий код соответствует последнему релизу
- **WHEN** пользователь запрашивает сводку состояния ресурсов системы
- **THEN** система показывает успешный статус синхронности кода с релизом

#### Scenario: Система запущена в development-режиме

- **GIVEN** система запущена через `npm run dev`
- **AND** текущий код соответствует последнему релизу
- **WHEN** пользователь запрашивает сводку состояния ресурсов системы
- **THEN** система показывает успешный статус синхронности кода с релизом

#### Scenario: Онлайн-доступ к информации о релизе недоступен

- **GIVEN** система не может получить онлайн-доступ к информации о последнем релизе
- **WHEN** пользователь запрашивает сводку состояния ресурсов системы
- **THEN** система не показывает ошибку синхронности кода с релизом
- **AND** система считает состояние допустимым для пользователя

### Requirement: Ограничение области диагностики релиза

Система SHALL в рамках этого change исправлять только успешное отображение состояния «код соответствует последнему релизу».

#### Scenario: Проблемная рассинхронизация не обрабатывается в этом change

- **GIVEN** существует ситуация, в которой код не синхронен последнему релизу
- **WHEN** система формирует статус синхронности
- **THEN** этот change не определяет новую обработку такого состояния
- **AND** этот change не требует сценариев восстановления, обновления или принудительной синхронизации
