# implement-project-workflow-title-id-workflow-image-to-component

Довести следующий пользовательский слой project workflow: пользователь создаёт проект, задаёт title и id, видит локальное хранение, затем создаёт в проекте несколько компонентов и из каждого компонента может явно запустить или продолжить workflow image-to-component через рабочую сессию без ручного поиска task/workbench.
