# implement-editorial-shell-style-foundation

Внедряет единый editorial visual language для product-shell интерфейса: светлые paper-surface, тонкие рамки, выразительную serif-типографику, инверсии active-state и общий ритм секций/карточек/действий без вмешательства в пользовательский preview и генерируемый контент.
