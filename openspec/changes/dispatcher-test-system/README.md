# dispatcher-test-system

Диспетчер тестовой подсистемы внутри `focus-quality`.

Этот change удерживает контракт тестового слоя как управляемую систему: фиксирует границы, roadmap и правила работы с проверками, а runtime- и tooling-изменения направляет в конкретные downstream `implement`/`fix` changes под собственным контролем.
