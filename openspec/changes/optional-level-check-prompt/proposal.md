# Optional level check prompt

## Зачем

Сейчас проверка результата уровня требует `onboarding/prompts/levels/<levelId>/check.md`. Если файл отсутствует, checking run становится технической ошибкой, даже когда уровню не нужны дополнительные скрытые требования проверки.

Нужно разрешить уровням не иметь отдельный `check.md`: в этом случае проверка должна продолжаться с пустой level-specific checking частью и использовать общий prompt-контур, пояснение уровня, картинки и рабочие файлы.

## Что меняется

- Отсутствующий `check.md` уровня трактуется как пустая строка.
- Наличие `check.md` по-прежнему добавляет его содержимое в checking instruction.
- Ошибка чтения отсутствующего файла больше не блокирует проверку уровня.
- Контракт фиксируется в `llm` и `onboarding-repo`.

## Влияние

- Runtime: `readLevelCheckPrompt` станет tolerant к отсутствию файла.
- Onboarding: авторы уровней смогут добавлять `check.md` только там, где нужны дополнительные требования.
- Тесты: source-contract проверит путь `check.md` и fallback на пустой prompt.
