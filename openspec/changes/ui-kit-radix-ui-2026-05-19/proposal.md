## Why

Нужно подключить Radix UI как отдельный Sandpack UI kit (не только как часть shadcn), чтобы можно было выбирать его на уровне проекта.

## Зависимости

Этот change зависит от `project-ui-kit-switching-2026-05-19` и не должен реализовываться до его полного завершения.

## What Changes

- Добавляем `uiKitId` для Radix UI в конфиг Sandpack UI kit'ов.
- Фиксируем зависимости: выбранный минимальный набор Radix-пакетов для smoke-проверки.
- Добавляем smoke-пример рендера Radix-компонента.
