## Why

Нужен исполнительский change для реализации постановки parent owner.

## What Changes

- Компонент проекта перестаёт искать уникальный свободный runtime slot в конечном каталоге.
- Для component workflow используется типовой runtime template, который можно переиспользовать между несколькими компонентами.
- Изоляция работы переносится на component-scoped project context, поэтому несколько компонентов одного проекта не смешивают prompt history, check-result и рабочие файлы.
- Сообщение о недоступности свободного workflow-слота исчезает из project flow.

## Impact

- Изменение закрывает конкретный исполнительский срез в рамках текущего parent owner.
