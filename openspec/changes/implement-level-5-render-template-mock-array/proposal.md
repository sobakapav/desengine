## Why

Для `level-5` уже разрешён файл `mock.ts`, а сам preview-контур уже умеет выбирать level-specific `App.tsx` template по уровню задачи. Но у пятого уровня пока нет собственного render-шаблона, который использовал бы `mock.ts` как источник нескольких вариантов рендера.

Нужно зафиксировать простой и предсказуемый контракт: если в `mock.ts` лежит массив, preview должен отрисовывать компонент для каждого элемента этого массива.

## What Changes

- Добавить для `level-5` собственный `onboarding/levels/level-5/sandpack/App.tsx`.
- Использовать уже существующий механизм level-owned Sandpack template, а не вводить новый runtime-путь.
- Зафиксировать прямое правило рендера:
  - для каждого элемента `mock`-массива отрисовывать `Component` с данными из этого элемента;
  - без дополнительной нормализации, эвристик и “умной” агрегации;
  - тупо в лоб через прямой перебор массива.
- Добавить/обновить unit-покрытие для выбора template и preview payload под `level-5`.

## Impact

- `level-labs`: пятый уровень получает собственный render-template.
- Preview начинает показывать все варианты из `mock.ts`, если `mock` задан как массив.
- Реализация опирается на уже существующий level-template runtime, а не дублирует его.
