## Why

Нужен исполнительский change для реализации задачи parent owner.

## What Changes

- Реализовать: Убрать конечный каталог свободных задач для компонентов проекта. Компонент должен открывать типовой workflow как тип задачи, а не искать уникальный свободный task slot. Ситуация 'нет доступных задач' должна исчезнуть.

## Impact

- Изменение закрывает конкретный исполнительский срез в рамках текущего parent owner.
