## ADDED Requirements

### Requirement: Wiki-система объединяет доступность для человека и пригодность для LLM

Система SHALL поддерживать wiki как общий knowledge-layer, в котором одни и те же продуктовые знания доступны человеку для чтения и навигации и пригодны для LLM-движка разработки как контролируемый контекст.

#### Scenario: Пользователь открывает wiki-единицу
- **WHEN** пользователь открывает wiki-материал о продуктовой сущности, решении или workflow
- **THEN** он получает понятное человеко-ориентированное описание и связи с соседними знаниями

#### Scenario: LLM-движок запрашивает knowledge-контекст
- **WHEN** LLM-движку нужен контекст о продуктовой сущности, решении или workflow
- **THEN** система может предоставить ту же knowledge-единицу в форме, пригодной для машинного использования
- **AND** смысл этой единицы совпадает с человеко-понятным представлением

### Requirement: Wiki-единицы имеют двойное представление и явное происхождение

Каждая wiki-единица MUST включать человеко-понятное содержание, машинно-структурированное представление и traceable ссылку на источник или источник происхождения знания.

#### Scenario: Создаётся или обновляется wiki-единица
- **WHEN** в wiki появляется новая knowledge-единица или редактируется существующая
- **THEN** она сохраняет narrative-представление для человека
- **AND** сохраняет структурированное представление для машинной обработки
- **AND** хранит явную ссылку на source-of-truth документ, change-артефакт или другой подтверждённый источник

### Requirement: Выборка wiki-контекста для LLM остаётся управляемой и traceable

Система SHALL собирать контекст для LLM из wiki выборочно, с возможностью понять, какие именно knowledge-единицы были использованы и откуда они произошли.

#### Scenario: Система подготавливает wiki-контекст для LLM
- **WHEN** workflow разработки собирает контекст для LLM-движка
- **THEN** в контекст попадают только релевантные wiki-единицы
- **AND** для каждой использованной единицы сохраняется traceability к её источнику
- **AND** downstream tooling может объяснить, почему именно этот knowledge-контекст был выбран
