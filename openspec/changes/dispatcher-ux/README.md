# dispatcher-ux

Диспетчер качества пользовательского опыта и UX-рисков внутри `focus-quality`.

Этот change удерживает UX как отдельный quality-контур: фиксирует границы ответственности, направляет downstream `producer`/`dispatcher`/`implement`/`fix` changes и требует человеко-понятную тестовую часть у каждого behavior-change, который меняет пользовательское взаимодействие.
