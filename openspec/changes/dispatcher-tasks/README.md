# dispatcher-tasks

Диспетчер системы задач онбординга внутри `focus-onboarding`.

Этот change удерживает продуктовые и контрактные границы task-системы: roadmap, связь с capability `task` и смежными capability, downstream `implement`/`fix` changes и обязательную тестовую опору для всех behavior-change в этой линии.

Отдельно эта линия удерживает migration onboarding-задач из level-центричной схемы в путь `проект -> workflow -> проверка/чеклист -> результат`, включая content-метаданные и связанные UI-волны.
