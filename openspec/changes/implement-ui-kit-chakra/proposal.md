## Why

Нужно подключить Chakra UI как Sandpack UI kit, чтобы он выбирался на уровне проекта через общий механизм переключения UI kit'ов.

## Зависимости

Этот change зависит от `dispatcher-ui-kit`: релизный срез по проектному переключению уже зафиксирован, а этот дочерний change расширяет набор доступных UI kit-адаптеров.

## What Changes

- Добавляем Chakra UI как новый `uiKitId` в Sandpack UI kit конфиг.
- Фиксируем необходимые npm-зависимости (включая peer зависимости, если есть).
- Добавляем минимальный bootstrap/импорты для корректного рендера.

## Acceptance Criteria

- Chakra UI доступен в списке выбора UI kit'а проекта.
- Переключение на Chakra UI работает «на лету» без перезагрузки страницы.
- Есть тестовое покрытие (unit + traceability; при необходимости e2e smoke).
