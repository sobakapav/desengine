# dispatcher-task-hints

Диспетчер линии task hints внутри `focus-onboarding`.

Этот change удерживает продуктовые и контрактные границы подсказок задач: roadmap, связь с capability `task` и `prompt-context`, downstream `implement`/`fix` changes и обязательную тестовую опору для всех behavior-change в этой линии.
