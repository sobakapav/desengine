# Output format

Use this as the default structure. Adapt the number of references and sections to the quality of the available material.

## Images

Show the strongest available reference images first, without a long introduction.

## Reference explanations

### 1. [Product or source name] — [short approach label]

**Approach:** One or two sentences explaining how the interface solves the task.

**What to take:** The transferable structural or interaction idea.

**Limitation:** A concise condition under which the example may not fit.

**Source:** Clickable citation or source link.

Repeat for the selected references.

## Most useful directions

Select 2–3 directions and explain briefly why they are the strongest fit. Do not select a winner when the request lacks enough context; instead state what each direction is best for.

## Formulation for the customer

Write one short paragraph in plain language, for example:

> В этих примерах нравится, что ключевая информация не распадается на одинаковые карточки. Сначала видно состояние выбранного объекта, затем — причины изменений и детали. Такой подход можно взять за основу, сохранив нашу структуру данных и сценарии.

Omit this section when it would not help or when the user asks only for raw references.
