# Desktop Release Checklist

Check release planning across:

- desktop build;
- platform installers;
- code signing;
- macOS notarization;
- auto-update channel;
- Figma plugin bundle;
- Figma Community review requirements;
- protocol compatibility;
- local endpoint compatibility;
- smoke tests for launch, pairing, import, playback, and update.

Do not treat CI passing as product release readiness unless desktop smoke and Figma plugin smoke are covered.
