# Ошибка с версиями системы. Не удалось проверить актуальность системы

![Проверка версии системы](images/version_error.png)

Первое, что нужно сделать это обновиться через терминал. 
На всякий случай сделайте копию файла конфигурации (desengine.config-example.txt) и папки с прогрессом (user).

В терминале в корне папки задачника выполните последовательно следующие шаги:

- Подтягиваем теги всех релизов командой 
`git fetch --all --tags`

- Переключаемся на последний релиз. Сейчас это v0.1.10 
`git checkout v0.1.10`

- Возвращаем файл конфигурации desengine.config.txt  и папку user, если они вдруг по каким-то причинам пропали

- Устанавливаем зависимости командой 
`npm install`

- Запускаем проверку, чтобы понять все ли собирается командой 
`npm run build`

- Если ошибок нет, запускам npm run dev и переходим по адресу http://localhost:3000 в вашем браузере.
