## Можно ли использовать бесплатную версию LLM?

Конечно. Для задачника прекрасно подойдет любая бесплатная версия: даже урезанных возможностей хватит за глаза и за уши.

## Нужно ли специально докупать токены?

Нет!

Ограничение на количество подходов в задачах выставлено в учебных целях.

Мы советуем вам экономить токены, потому что именно это приходится делать специалисту, постоянно использующему LLM в работе.

## Как получить API ключ к OpenAI?

1. Залогиньтесь на [OpenAI Platform](https://platform.openai.com), используя тот же аккаунт, что и в обычный OpenAI.
2. На странице [API-ключей](https://platform.openai.com/api-keys) нажмите **Create new secret key**. 
3. Задайте имя ключа (например, desengine).
4. Система сгенерирует буквенно-цифровой код (токен). Сразу скопируйте его и сохраните в безопасном месте. Больше вам его не покажут, и если потеряете — придется создавать новый.

## Как получить бесплатный API-ключ Gemini? 

1. Включите VPN. Выберите локацию, где официально поддерживается [Google AI Studio](https://aistudio.google.com/) (например, США, Германия или любая страна Азии).
2. Перейдите на сайт [aistudio.google.com](http://aistudio.google.com/) под своей учетной записью Google.
3. Нажмите **Get API key** в левом верхнем углу меню.
4. Выберите **Create API key in new project**. Система создаст ключ, скопируйте и сохраните его.

## Как получить API-ключ для DeepSeek?

1. На сайте [OpenRouter](openrouter.ai) залогиньтесь через Google, GitHub или email. 
2. На [странице ключей](openrouter.ai/keys) нажмите **Create API Key**.
3. Назовите ключ (например, desengine).
4. Если есть поле лимита расходов, можно поставить минимальное значение или оставить по умолчанию (для бесплатной LLM).
5. Нажмите **Create**. Скопируйте ключ и сохраните.

## Что делать дальше?

Укажите в desengine.config.txt:

- выбранную LLM. Например, LLM_PROVIDER=gemini
- ее модель. Например, DESENGINE_DEEPSEEK_MODEL=deepseek/deepseek-v4-flash:free
- ваш API-ключ. Например, OPENAI_API_KEY=вотпрямосюдаипишитеего

Сохранитесь и запустите в терминале команду npm run dev (из корневой папки проекта).
